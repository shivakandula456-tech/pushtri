# Synthetic test fixtures (NOT production data)

Every file under `data/fixtures/races/` is synthetic and was generated by `test-fixture-generator-1.0.0`. None of it came from AT The Races or any other real source.

- Every race record carries `"testData": true`, `"dataset": "test-fixture"` and `"source": "test-fixture-generator"`.
- Course names end with `(TEST)`; runner and people names are invented (`Fixture Alpha`, `Test Jockey A`, ...).
- `fixtures-manifest.json` lists each fixture with the evaluation the locked Phase 1 rules must produce, including the expected rejection code and candidate. `test/fixtures.test.js` recomputes every evaluation and fails if reality drifts from the manifest.
- The website shows a visible banner whenever a fixture dataset is loaded, and backtests exclude fixtures unless the user explicitly opts in.
- Never copy these files into `data/races/` and never present them as collected results.
